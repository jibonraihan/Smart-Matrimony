\# 💍 Smart Matrimony



An advanced Matrimony \& Wedding Event Management System developed using PHP and MySQL.



\---



\## ✨ Features



\- User Registration \& Login

\- Multi-Step Profile Creation

\- Partner Matching

\- Search Profiles

\- Bookmark/Favorites

\- Chat System

\- Wedding Service Booking

\- Admin Panel

\- Authenticator Panel

\- Profile Verification



\---



\## 🛠️ Technologies Used



\- PHP

\- MySQL

\- HTML5

\- CSS3

\- JavaScript

\- Bootstrap

\- XAMPP



\---



\## 🚀 Installation



1\. Clone the repository



```bash

git clone https://github.com/jibonraihan/Smart-Matrimony.git

```



2\. Copy the project into:



```

xampp/htdocs/

```



3\. Import the database:



```

database/smart\_matrimony.sql

```



4\. Start Apache \& MySQL from XAMPP.



5\. Open:



```

http://localhost/smart\_matrimony

```
